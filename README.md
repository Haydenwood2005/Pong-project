# Pong-project
A basic retro game, opening in a local terminal when ran on VSCode, allowing for single or multiplayer enjoyment.

## Description
This project will use my initiative and develop my skills as a programmer, this course follows my own knowledge, youtube tutorials, and information gathered on google

## Game Specification

Players: one or two
Tools used: VSCode, specifically importing turtle 

key features include, game score, bot difficulty in start menu along with other menu features, such as colours, one or two players, and sound options.

## Controls
If one player, use up and down arrow, if second player is present, use W and S.
